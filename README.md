# OpenStarbound UA (Український переклад Starbound) 🇺🇦

[![OpenStarbound Compatible](https://img.shields.io/badge/OpenStarbound-Compatible-blue.svg)](https://github.com/OpenStarbound/OpenStarbound/releases)
[![AI Translated](https://img.shields.io/badge/Translation-AI%20Generated-purple.svg)]()

Це глобальна українська локалізація гри **Starbound** (понад 55 000 рядків тексту), розроблена на базі [OpenStarbound](https://github.com/OpenStarbound/OpenStarbound/releases). 

Незважаючи на те, що мод створювався з урахуванням OpenStarbound, він **повністю сумісний з оригінальною (ванільною) версією гри** та перекладає її.

## 🤖 Особливості перекладу (ШІ без редактури)

Цей переклад був повністю виконаний за допомогою сучасних моделей штучного інтелекту без ручного вичитування (редактури) всього обсягу тексту. 

Незважаючи на машинний переклад, до системи були закладені суворі правила лору Starbound для збереження унікального колориту рас:
- **Флорани:** розмовляють у третій особі та протяжно шиплять («сссмачно»).
- **Ґлітчі:** починають кожну фразу з емоції («Зацікавленість.», «Обурення.»).
- **Новакіди:** розмовляють із використанням гуцульського діалекту для передачі атмосфери «дикого заходу» в космосі («легінь», «файно»).
- **Термінологія:** збережено адаптовані назви, такі як *Земний Захист* (Terrene Protectorate), *Дбайливець* (Cultivator), *Міннаук* (Miniknog), *Великий Мавп* (Big Ape) та *Б.Ш.І.* (S.A.I.L.).

## ⚠️ Важливі зауваження

- **Графіка не перемальовувалась.** Усі написи, які розробники Starbound «запекли» безпосередньо у текстури (наприклад, заголовки вікон "CHARACTER CREATION" чи "SELECT CHARACTER" на фонових картинках), залишилися англійською. 
- **Можливі смислові неточності.** Оскільки переклад робив ШІ без контексту конкретних ігрових ситуацій, деякі діалоги або описи можуть здаватися дивними чи неточними. 
- **Оригінальні бренди збережено.** Ігрові корпорації та бренди (наприклад, *Shade Co.*, *Teklacki*) свідомо залишені без перекладу.

## 🛠 Інсталяція

1. Завантажте файл `OpenStarboundUA_1.0.0.pak` з розділу **Releases**.
2. Перемістіть завантажений файл у папку `mods` вашої гри:
   - *Для Steam версії:* `.../Steam/steamapps/common/Starbound/mods/`
   - *Для OpenStarbound:* `.../OpenStarbound/mods/`
3. Запустіть гру і насолоджуйтесь українською!

## 📌 Підтримка та оновлення

**Активна підтримка чи повноцінна редактура моду не планується.** 
Цей переклад створювався "як є" для особистого проходження. Можливо, сюди час від часу будуть завантажуватися невеликі виправлення, на які я натраплятиму під час власної гри, але масштабного вичитування тексту не очікується.

Якщо ви бажаєте форкнути репозиторій та самостійно покращити переклад або перемалювати текстури — you are welcome!
